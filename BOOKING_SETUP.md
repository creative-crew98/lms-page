# Simple consultation slots

Google Calendar has been removed from the form. After all eight answers save, users pick a date and one available time, then confirm. Availability covers the next 14 calendar days, Monday-Saturday, in Asia/Kolkata. Times: 10:30 AM, 12:00 PM, 1:30 PM, 3:00 PM, 4:30 PM, 6:00 PM. Sundays, past times, and booked slots are excluded. The UI refreshes availability every 20 seconds while visible. Confirming rechecks the slot under the Apps Script lock, so a stale browser cannot double-book it.

Paste the entire updated google-apps-script/Code.gs into your existing Google Sheet Apps Script project. Update the existing web-app deployment: Deploy > Manage deployments > Edit > Version: New version > Deploy. Keep the same /exec URL used by Form.tsx. Run setup once if you have not configured your sheet. The script appends Booking date (IST) and Booking time (IST) in columns R and S without deleting existing lead rows. Lead-ID retries update/return the same booking instead of inserting duplicates. One reservation is allowed per date/time across this script's Leads sheet. Manual edits or other scripts that bypass its lock must not create reservations.

Bookings do not create a Google Calendar event or Google Meet link. The selected date and time are recorded in the same lead row as contact details and all answers. This is a static exported website using the existing Google Apps Script web app; no backend is copied into the CRM. The Apps Script update must be deployed before the new booking UI can fetch availability or reserve times.

## CRM lead sync

In Apps Script, open **Project Settings ? Script properties** and add `CRM_LEAD_RECEIVER_URL` with `https://YOUR_PROJECT_REF.supabase.co/functions/v1/lead-ingest`, and `CRM_LEAD_INGEST_SECRET` with the same server secret saved as `LEAD_INGEST_SECRET` in Supabase. The script accepts only an HTTPS Supabase function URL. Do not put the database service-role key here. Column T records `Delivered to CRM` or `Pending - retry from Apps Script`; it is added only if T1 is empty or already the matching heading. Existing data is kept. Run `retryPendingCrmLeads` manually or create a time-driven trigger to retry pending deliveries. Existing rows are not imported automatically; use the manual `backfillExistingLeadsToCrm` operation only when you explicitly want to sync prior leads. The Apps Script CRM delivery code is in the current `google-apps-script/Code.gs` and will take effect after updating the web app deployment.
